⚙️ Guide d'installation du tableau de bord

En 3 étapes simples, installez le tableau de bord directement dans votre Chrome — aucun logiciel à installer.

1
Afficher la barre de favoris Chrome
Elle doit être visible en haut du navigateur

Si la barre de favoris n'est pas visible, appuyez sur Ctrl + Maj + B (ou ⌘ + Maj + B sur Mac) pour l'afficher.

🔒 gaia.agirabcd.fr/admin/mission/mission/accueil.html
⭐ Favoris :
📊 Tableau de bord GAÏA
← Votre signet apparaîtra ici
Astuce : Vous pouvez aussi aller dans le menu Chrome (les 3 points ⋮ en haut à droite) → Favoris → Afficher la barre de favoris.
2
Glisser le bouton vers la barre de favoris
Maintenez le clic et faites glisser le bouton doré jusqu'à la barre

Cliquez sur le bouton ci-dessous, maintenez le clic enfoncé, puis faites glisser vers votre barre de favoris Chrome en haut. Relâchez quand vous voyez l'emplacement s'ouvrir.

👇 Glissez ce bouton vers votre barre de favoris
GAIA Extracteur V5
☝️ Cliquez-glissez vers la barre de favoris de Chrome
Si le glisser-déposer ne fonctionne pas : Faites un clic droit sur le bouton doré → Ajouter aux favoris… → Choisissez la barre de favoris.
3
Utiliser le tableau de bord
À faire chaque fois que vous voulez ouvrir le tableau de bord

1. Connectez-vous à Gaïa normalement : gaia.agirabcd.fr

2. Une fois connecté, cliquez sur votre favori GAIA Extracteur V5 dans la barre.

3. Le tableau de bord s'ouvre par-dessus la page Gaïa. Choisissez vos filtres et cliquez sur Rechercher.

4. Pour fermer le tableau, cliquez sur le bouton ✕ Fermer en haut à droite — ou recliquez sur le favori.

📊 Résultat : Un fichier Excel est généré et téléchargé automatiquement avec tous les feuillets du tableau de bord.
🎉
C'est tout ! Le tableau de bord utilise votre session Gaïa déjà ouverte — pas besoin de vous reconnecter. Il se partage facilement : donnez simplement ce fichier d'installation aux autres membres de la DI.
👥
Partager avec les membres de la DI
Chaque membre fait la même installation une seule fois

Envoyez ce fichier GAIA_Installation.html par email aux membres de la DI. Ils l'ouvrent dans Chrome et suivent les 3 étapes ci-dessus. Aucun logiciel, aucun serveur, aucune configuration réseau nécessaire.

⚠️
Chaque personne doit être connectée à Gaïa dans Chrome avant de cliquer sur le favori. Si le tableau affiche ❌ Non connecté, retournez sur gaia.agirabcd.fr, connectez-vous, puis recliquez sur le favori.
